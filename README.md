Perfumaria

Descrição
O site foi criado para um e-commerce de uma perfumaria, com os produtos á disposição para serem adicionados no carrinho.

Funcionalidades
Página Inicial: Apresenta uma vitrine de perfumes.
Navegação: Utiliza React Router para navegação entre as páginas.
Menu: Organiza as páginas do site no cabeçalho.
Sistema de Compras: Botão nos perfumes onde é adicionado no carrinho, podendo aumenta ou diminuir as quantidades e fazendo o cálculo do preço total.

🛠️ Tecnologias Utilizadas
React - Biblioteca JavaScript para construção de interfaces de usuário.
React Router - Gerenciamento de rotas em aplicações React.
Bootstrap - Framework CSS para estilização e responsividade.
React Bootstrap - Componentes Bootstrap para React.
FontAwesome - Ícones para incrementar o design.

Como Executar o Projeto
Siga as etapas abaixo para clonar e executar o projeto localmente:
1. Clonar o Repositório
git clone https://github.com/vaghenrique/FSN2-GRUPO04-PERFUMARIA.git
2. Navegar até o Diretório do Projeto
cd perfumaria
3. Instalar as Dependências
npm install
4. Iniciar o Servidor de Desenvolvimento
npm start
5. Acessar o Projeto
Abra seu navegador e acesse http://localhost:3000 para ver o site em funcionamento.
